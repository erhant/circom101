# Intermediate

These examples are mostly puzzles where the circuit verifies a solution, instead of finding it:

- [Sudoku](./sudoku.md) is the classic zero-knowledge example.
- [Two Sum](./two-sum.md) verifies the answer to the famous LeetCode problem.
- [N-Queens](./n-queens.md) verifies a placement of queens on a chessboard.
- [Fixed-Point Arithmetic](./fixed-point.md) computes with fractions, as needed for zkML.
